# qawale — 4×4の山くずし対戦ボードゲーム

山をくずして自分の色を並べる、Gigamic『Kawale』風の対戦パズル。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/qawale/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

4×4 の盤。4 つの角には中立の石（黄土色）が 2 個ずつ積んである。各プレイヤーは自分の色の石を 8 個持つ。

- 手番では、石のある山を 1 つ選ぶ。自分の石を 1 個その上に積み、山ごと手に取る。
- 取った山を一番下の石から順に 1 個ずつ、隣（上下左右）のマスへ配っていく。直前に通ったマスへすぐ戻ることはできない（ぐるっと回って戻るのは可）。
- 各マスの一番上に見える石の色が、縦・横・斜めのどれか 1 列（4 マス）で揃えば勝ち。両者が同時に揃ったときは、その手を指した側の勝ちとする。
- 両者が 8 個ずつ置き終えて（16 手）並びがなければ引き分け。

操作: 山をタップ → 置いていく先のマスを順にタップ。置き始める前（まだ 1 個も置いていない）なら、選んだ山をもう一度タップすると選び直せる。

モード: CPU 対戦（よわい / ふつう / 最強、先手・後手を選べる）、2 人対戦（1 台で交互に）。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
